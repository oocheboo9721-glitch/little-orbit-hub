나의 기록이 머무는 곳

최종 수정: 2026년 11월 7일

이 기기에 저장

일기 제목·내용·날짜·기분, 허브에 추가한 앱 링크와 즐겨찾기는 현재 브라우저의 localStorage에 저장됩니다. 로그인이나 서버가 필요하지 않습니다. 다른 기기와 동기화되지 않으며 브라우저 데이터 삭제·시크릿 모드 종료 시 사라질 수 있습니다. 공용 기기에서는 사용을 피하고 필요한 기록은 JSON으로 백업하세요.

Firebase 클라우드 저장과 Google 로그인

Firebase 프로젝트가 연결된 경우 사용자가 클라우드 모드를 선택하고 Google 로그인을 완료해야 사용할 수 있습니다. Google/Firebase Authentication은 계정 식별자·이메일·프로필 등 기본 로그인 정보를 처리할 수 있습니다. 앱은 별도의 프로필 문서를 만들거나 이메일을 일기에 저장하지 않습니다. 로그인 상태는 이 탭의 세션 저장소에 보관되며, 일기 본문은 Firestore 메모리 캐시를 사용해 디스크 캐시에 저장하지 않습니다.

일기 제목·내용·날짜·기분·생성 및 수정 시각은 Firebase Cloud Firestore의 본인 UID 하위에 저장됩니다. 규칙은 본인 계정의 문서만 접근하도록 설계됩니다. 프로젝트 관리자는 관리 권한으로 데이터에 접근할 수 있으며 종단간 암호화를 제공하지 않습니다. 로컬 일기는 자동으로 클라우드에 옮기지 않습니다. 클라우드 모드에서는 인터넷 연결이 필요합니다.

삭제와 백업

각 일기를 열어 삭제할 수 있습니다. 삭제 후 앱에서 복구할 수 없습니다. 로그아웃은 클라우드 일기를 삭제하지 않습니다. JSON 백업은 전체 본문을 포함하므로 공개 저장소나 공유 폴더에 올리지 마세요. 앱에는 JSON 가져오기 기능이 없습니다.

외부 연결과 운영 범위

광고·방문 추적·분석 도구를 사용하지 않습니다. GitHub Pages는 페이지 제공에 필요한 접속 정보를 자체 정책에 따라 처리할 수 있습니다. 클라우드 기능 사용 시 Google Firebase SDK와 Google 서비스에 연결됩니다. 외부 앱 링크는 새 탭으로 열며 참조 페이지 정보를 전달하지 않습니다.

개인 기록용 도구입니다. 학생 이름·학교·성적·건강 정보 등 타인의 민감한 개인정보를 입력하지 마세요. 서비스 운영 및 데이터 처리는 연결한 Firebase 프로젝트 운영자의 책임 아래 이루어집니다.

허브 공개 등록

‘교사의 별자리’ 등록 신청에는 허브 이름·소개·공개 주소·분류·문양만 전달합니다. 개인 일기, 로그인 정보, 기기별 앱 목록은 신청에 포함되지 않습니다.
